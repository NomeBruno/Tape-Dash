📼 Tape Dash

Um jogo arcade retro-futurista com estética cyberpunk/synthwave focado em agilidade, reflexos e pontuação.

🎮 Sobre o Projeto

Tape Dash é um jogo web desenvolvido com tecnologias nativas do desenvolvimento front-end (HTML, CSS e JavaScript). Com um visual fortemente inspirado no universo cyberpunk, o projeto conta com:

Modo de Jogo Arcade: Teste seus reflexos e conquiste a maior pontuação possível.

Tabela de Pontuações: Registro das melhores pontuações para acompanhar seu progresso.

Interface Retro-Futurista: Design com efeitos visuais neon, estilo VHS/Fita cassete e feedback interativo.

🌐 Acesse e jogue agora: https://nomebruno.github.io/Tape-Dash/

🚀 Tecnologias Utilizadas

O projeto foi construído utilizando:

HTML5: Estruturação semântica das páginas.

CSS3: Estilização responsiva, efeitos neon, animações e layout.

JavaScript (ES6+): Lógica do jogo, manipulação do DOM e controle da pontuação.

GitHub Pages: Hospedagem e deploy contínuo do projeto.

💻 Como Rodar Localmente

Caso queira executar e testar o projeto na sua máquina:

Clone o repositório:

git clone https://github.com/nomebruno/Tape-Dash.git


Navegue até a pasta do projeto:

cd Tape-Dash


Abra no navegador:

Basta abrir o arquivo index.html diretamente em seu navegador preferido ou utilizar extensões como o Live Server no VS Code.
